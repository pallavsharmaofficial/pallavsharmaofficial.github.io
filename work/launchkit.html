Launchkit

The parts of shipping a Flutter app to Google Play that a machine can do, done by a machine.

Private repository

Why

Publishing an app means the same forty steps every time: store listings in each language, graphics at the right sizes, screenshots, signing, release tracks. Doing that by hand once is tedious; doing it for every app is a waste.

What it does

Scaffolds a new app, generates the store assets, and drives the Google Play Developer API to write listings, upload graphics and push a release, without opening the console.

It is what put the apps on this page into testing.

  • Play Developer API v3
  • Listings and graphics in every locale
  • Release tracks from the command line
